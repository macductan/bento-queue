### F-1: Service layer import Wails runtime trực tiếp (Medium — Defer)

**Nguồn:** `projects/service/config.go:15,202`

```go
wailsRuntime "github.com/wailsapp/wails/v2/pkg/runtime"
...
wailsRuntime.EventsEmit(ctx, "startup-error", message)
```

`ConfigService.emitStartupError` tạo compile-time dependency từ `service/` package lên Wails runtime, vi phạm tinh thần AD-5 ("Service testable không cần Wails context"). **Disposition:** Defer — không ảnh hưởng production (app.go luôn pass đúng Wails ctx). Fix khi cần test `Initialize()` toàn phần.

### F-5: Collection data path dùng `os.UserCacheDir()` thay vì XDG data dir (Medium — Fix)

**Nguồn:** `projects/service/config.go:83-87`

```go
func (s *ConfigService) resolveDefaultCollectionRoot() (string, error) {
    cacheDir, err := os.UserCacheDir()  // <- Cache, không phải Data
    ...
    return filepath.Join(cacheDir, appName, "collections", "default"), nil
}
```

`epic-1-context.md:36` ghi: "Data tại `{dataDir}/hecto-api/collections/default/` (XDG convention)".

Trên Linux: `os.UserCacheDir()` → `~/.cache` (có thể bị xóa bởi system cleaners như `systemd-tmpfiles`), trong khi XDG Data dir là `~/.local/share`. Trên macOS: `UserCacheDir()` → `~/Library/Caches` (nên là `~/Library/Application Support`). Collection data của user là **persistent data**, không phải cache.

**Disposition:** Fix-now trước release production. Action item A-2.
