- (direction) Tạo technical spec cho nhóm tính năng Năng suất Request từ improve.md (mục 14, 15, 16)
- (decision) Đồng bộ hai chiều giữa URL Bar và bảng Query Params phải bảo toàn cú pháp biến môi trường {{...}} và không gây vòng lặp cập nhật vô tận
- (decision) Tắt kích hoạt (disable) query param sẽ ẩn param đó khỏi URL bar nhưng vẫn giữ nguyên dòng cấu hình trong tab Params
- (decision) Tính năng Copy as cURL xuất đầy đủ Method, URL, Params, Headers, Auth, Body và escape an toàn cho POSIX shell, tự động giải quyết biến môi trường theo active environment
- (decision) Auto-save tự động lưu ngầm với debounce 800ms, hỗ trợ flush tức thì khi chuyển request hoặc đóng ứng dụng, lưu thầm lặng không spam Toast gây nhiễu
- (capability) CAP-1: Người dùng có thể đồng bộ hai chiều tức thì giữa thanh URL bar và bảng cấu hình Query Params
- (capability) CAP-2: Người dùng có thể xuất và sao chép request hiện tại thành lệnh cURL hoàn chỉnh vào clipboard chỉ với một click
- (capability) CAP-3: Hệ thống tự động lưu các thay đổi của request xuống file storage với cơ chế debounce và flush khi chuyển request
- (constraint) Định dạng file lưu trữ request trên ổ đĩa (JSON/YAML) phải tương thích tuyệt đối với schema hiện tại
- (constraint) Cú pháp biến môi trường {{...}} trong URL hoặc Params không được bị encode hay phá vỡ khi phân tích cú pháp query string
- (non_goal) Không hỗ trợ tính năng Import lệnh cURL ngược lại thành Request trong phạm vi Spec này (dành cho mục cải tiến sau)
- (non_goal) Không triển khai cơ chế Undo/Redo lịch sử thay đổi phiên làm việc trong phạm vi Spec này (đã có mục 5 riêng trong improve.md)
- (event) Validation Pass 1 (Coherence) và Pass 2 (Preservation) đạt chuẩn Spec Law
- (decision) Bẻ Spec thành 3 User Stories tuần tự: 1. Bi-directional URL & Query Params sync, 2. Copy as cURL export, 3. Debounced Auto-save with flush-on-switch
- (event) stories.yaml được khởi tạo và kiểm tra hợp lệ với stories-schema
