- (capability) CAP-2: Hỗ trợ đầy đủ các định dạng Body: XML (application/xml), x-www-form-urlencoded (KVPair editor + URL encoding) và multipart/form-data (KVPair editor + multipart boundary trên Go ExecutorService) đồng bộ với RequestTabs, DefaultHeadersTable, buildExecuteRequest và cURL generator/parser (Mục 26).
- (capability) CAP-3: Cấu hình Authentication theo từng Environment hoặc Global (auth_envs + auth) ở cả 3 cấp Collection, Folder và Request; tự động kế thừa theo thứ tự ưu tiên Request (Env -> Global) > Folder (Env -> Global) > Collection (Env -> Global) (Mục 34).
- (constraint) Quy tắc an toàn dữ liệu khi test (Mục 19): Toàn bộ unit/component tests chỉ thao tác trên Test-Collection hoặc t.TempDir().
