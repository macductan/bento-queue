- (capability) CAP-1: Binary CLI độc lập hecto (projects/cmd/hecto/main.go) thuần Go, không phụ thuộc Wails/GTK/WebKit, tái sử dụng 100% các package model, storage, service, slug và tách phụ thuộc wailsRuntime khỏi ConfigService qua callback tùy chọn.
- (capability) CAP-2: Shared TS Execution Engine qua //go:embed + goja (projects/engine): bundle projects/frontend/src/utils/headless-engine.ts thành headless-engine.js và chạy trên goja kèm polyfills (btoa, atob, TextEncoder, TextDecoder, console) để thực thi 4-Tier Variable Resolution, Auth Inheritance, Inherited Headers, Script Runner (ha.*/pm.*) và lệnh hecto run đồng nhất 100% với giao diện Vue.
- (capability) CAP-3: Giao thức Stateless CLI hỗ trợ --json trả về chuẩn model.Result kèm lệnh tự khám phá hecto agent-guide in trực tiếp nội dung chuẩn SKILL.md ra stdout (và ghi chú hướng dẫn AI Agent ở dòng đầu tiên của hecto --help).
- (capability) CAP-4: Ma trận lệnh trực giao hecto <entity> <verb> cho 4 thực thể (collection, env, folder, req) với list/tree, get, create (1 bước), update (Read-Merge-Write patch), delete, move + lệnh hecto import (Postman v2.1 & cURL), hỗ trợ định danh bằng cả UUID lẫn tên/đường dẫn phân cấp tên.
- (capability) CAP-5: Đồng bộ dữ liệu 3 lớp an toàn giữa CLI và Wails Desktop: giữ Atomic Write (.tmp -> fsync -> rename), nâng cấp FileSystem.FindByUUID tự chữa lành (Exists(path) check + fallback walk), bỏ IndexRebuild quét đĩa lặp trong CollectionService.GetTree, và bổ sung fsnotify watcher (lọc self-write) kèm nút Smart Reload riêng biệt trên UI (giữ nguyên expandedFolders, đồng bộ tabStore, bảo vệ tab đang gõ dở isDirty).
- (constraint) Không viết lại hoặc duy trì 2 bản logic song song giữa Go và TypeScript cho 4-Tier Variable Resolution, Auth Inheritance, buildExecuteRequest và Script Runner; giữ 1 nguồn sự thật duy nhất tại projects/frontend/src/utils/.
- (constraint) Binary hecto không được import github.com/wailsapp/wails/v2 hoặc bất kỳ thư viện đồ họa C/GTK/WebKit nào; ConfigService dùng callback tùy chọn để emit lỗi startup khi chạy trong Wails.
- (constraint) Mọi thao tác update trên CLI (collection, env, folder, req) bắt buộc thực hiện Read-Merge-Write (patch) để bảo toàn nguyên vẹn các trường không được chỉ định trên dòng lệnh.
- (constraint) Trên Wails UI, tuyệt đối không dùng window.location.reload() và không tự động reload cây thư mục ngầm khi focus/watcher báo sự kiện; chỉ hiển thị chấm báo hiệu trên nút Reload và chỉ thực thi smartReload() khi người dùng chủ động nhấn nút, bảo vệ tuyệt đối tab có isDirty = true.
