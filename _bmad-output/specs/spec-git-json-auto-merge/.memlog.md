- (capability) CAP-1: Trích xuất 3 phiên bản (BASE :1:, OURS :2:, THEIRS :3:) từ Git index và tự động thực hiện thuật toán 3-Way JSON Merge ở cấp trường dữ liệu và phần tử KVPair cho Request (<uuid>.json), Folder (_folder.json), Environment (environments/*.json) và Collection (collection.json), tự động git add và hoàn tất merge commit nếu không còn xung đột.
- (capability) CAP-2: Phát hiện xung đột thực sự ở cấp trường (Field-Level Conflict khi cả 2 bên cùng sửa 1 trường scalar hoặc cùng 1 key KVPair thành 2 giá trị khác nhau) và xung đột Xoá vs. Sửa (Delete vs. Edit conflict), trả về cấu trúc chi tiết kèm giá trị base, ours, theirs trong phản hồi GIT_CONFLICT cho Frontend.
- (capability) CAP-3: Giao diện Visual Conflict Resolver (GitConflictResolverModal.vue tích hợp cùng GitSyncModal.vue) hiển thị Diff 2 cột trực quan (Bản của bạn - Local vs. Bản từ xa - Remote), hỗ trợ chọn nhanh 1 click cho từng trường riêng lẻ (Field-by-field pick), chọn toàn bộ bản Local/Remote, hoặc chọn Giữ/Xoá khi xảy ra Delete vs. Edit conflict.
- (capability) CAP-4: Hỗ trợ Wails bindings ResolveGitConflict để lưu kết quả lựa chọn từ UI xuống file JSON trên đĩa, hoàn tất merge commit + reload dữ liệu UI, và AbortGitMerge (git merge --abort) để huỷ quá trình merge quay về trạng thái ban đầu an toàn.
- (constraint) Giữ vững triết lý File = Truth: Mọi kết quả 3-Way Auto-Merge và Manual Resolve đều ghi trực tiếp thành file JSON hợp lệ trên ổ đĩa, tương thích hoàn toàn với Git CLI thông thường.
- (constraint) Hiệu năng & An toàn: Quá trình phân tích 3-Way JSON Merge trên Go backend phải chạy dưới 50ms/file; kiểm tra chống path traversal cho mọi đường dẫn file resolve; mọi lệnh Git thực thi qua exec.CommandContext không dùng shell; toàn bộ kiểm thử tự động chỉ thao tác trên t.TempDir() hoặc Test-Collection.
- (event) Self-Validate Pass 1 (Coherence) & Pass 2 (Preservation): PASS — Toàn bộ 4 capabilities (CAP-1..CAP-4) và companion git-merge-architecture.md đáp ứng đầy đủ Spec Law 1-8 và bảo toàn 100% yêu cầu từ bản mô tả của người dùng.
- (decision) Xử lý chính xác ngữ cảnh git stash pop vs git merge: Khi conflict phát sinh từ git stash pop (không có MERGE_HEAD), đảo chiều stage (:2: là THEIRS/Remote, :3: là OURS/Local) và hỗ trợ AbortGitMerge khôi phục đúng bản local từ stash mà không mất dữ liệu.
- (decision) Hỗ trợ 3-Way JSON Merge đệ quy cho trường body.content khi body.type == 'json' và nội dung parse được thành JSON Object, cho phép tự động gộp các key không trùng bên trong JSON payload của Request.
- (decision) So khớp danh sách KVPair (headers, params, path_params, variables, form_data, urlencoded) theo cặp (Key, occurrenceIndex) để bảo toàn các dòng trùng Key hoặc dòng đang tắt (enabled: false), đồng thời bỏ qua các dòng nháp rỗng hoàn toàn.
- (decision) Trên GitConflictResolverModal.vue, hiển thị tiến độ giải quyết (Đã xử lý X/Y file) và chỉ cho phép bấm 'Xác nhận & Hoàn tất Đồng bộ' khi toàn bộ các trường/file xung đột đã được người dùng chủ động chọn (qua click từng trường, nút Chọn toàn bộ Local/Remote của file, hoặc nút Chọn toàn bộ cho tất cả file).
- (decision) Tự động flush (lưu xuống đĩa) Request hoặc Folder đang mở có trạng thái isDirty trước khi thực thi Git Pull / Git Push để tránh mất thay đổi đang gõ trên UI.
