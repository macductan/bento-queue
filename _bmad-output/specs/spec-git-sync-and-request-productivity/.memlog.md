- (capability) CAP-1: Người dùng có thể cấu hình Git Remote URL (HTTPS/SSH) theo từng Collection và thực hiện Git Pull / Git Push trực tiếp từ UI gọi Go backend thực thi git pull / git push trong thư mục Collection, kèm báo lỗi rõ ràng nếu xảy ra xung đột (conflict) để người dùng tự xử lý tay.
- (capability) CAP-2: Khi người dùng dán (paste) chuỗi lệnh cURL vào thanh URL Bar, hệ thống tự động nhận diện và parse thành HTTP Method, URL, Query Params, Headers, Auth (Basic/Bearer) và Body trên Request hiện tại (Mục 35).
- (capability) CAP-3: Người dùng có thể mở tab Preview cURL trên RequestTabs để xem câu lệnh cURL hoàn chỉnh đa dòng đã phân giải biến môi trường 4 tầng và sao chép nhanh (Mục 33).
- (capability) CAP-4: Người dùng có thể chọn các HTTP Method mở rộng (HEAD, OPTIONS) hoặc gõ bất kỳ Custom HTTP Method nào (PURGE, PROPFIND, LINK,...) trong dropdown Method của UrlBar (Mục 27).
- (capability) CAP-5: Đưa dropdown chọn loại Body (None, JSON, Text,...) lên cùng hàng bên phải của thanh RequestTabs để tiết kiệm không gian dọc cho BodyEditor (Mục 24).
- (capability) CAP-6: Sửa lỗi Ctrl+Z (Undo) và Ctrl+Y / Ctrl+Shift+Z (Redo) trên mọi ô input và textarea trong toàn ứng dụng thông qua cơ chế quản lý ngăn xếp Undo/Redo theo từng phần tử DOM (Mục 23).
- (constraint) Quy tắc an toàn dữ liệu khi test (Mục 19): Mọi kiểm thử Go test và Vitest chỉ được phép tạo và thao tác trên Test-Collection hoặc t.TempDir(), nghiêm cấm đụng chạm dữ liệu thật của người dùng.
- (constraint) Bảo mật thực thi lệnh Git: Mọi lời gọi exec.Command('git', ...) trên Go backend phải truyền đối số tách biệt (không ghép chuỗi qua shell sh -c), giớiicz thư mục làm việc (cmd.Dir) строго bên trong thư mục của Collection đã xác thực, và kiểm tra Git Remote URL hợp lệ (không bắt đầu bằng dấu '-' để chống argument injection).
- (decision) Chia Spec Giai đoạn 1 thành 3 stories độc lập: Story 1 (Ctrl+Z Undo/Redo, Custom HTTP Method & Inline Body Type Dropdown), Story 2 (cURL Paste Auto-Parser & Resolved cURL Preview Tab), Story 3 (Per-Collection Git Remote Config, Git Pull & Git Push Sync).
- (event) Self-Validate Pass 1 (Coherence) & Pass 2 (Preservation): PASS — Toàn bộ 6 capabilities đáp ứng Spec Law 1-8, bảo toàn 100% yêu cầu từ Giai đoạn 1 và improve.md (Mục 23, 24, 27, 33, 35 và Git Sync cơ bản).
- (event) Story Breakdown Validation: PASS — 3 stories trong stories.yaml tuân thủ đầy đủ schema và quy tắc định danh.
